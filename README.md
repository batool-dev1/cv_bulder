# 📄 Arabic CV Builder (منشئ السيرة الذاتية باللغة العربية)

An intuitive, responsive web application designed to help job seekers create, customize, and export professional Arabic resumes quickly and effortlessly.

🌐 **Live Demo:** [Arabic CV Builder](https://batool-dev1.github.io/cv_bulder/)

---

## 🌟 Key Features

- **Interactive Form Input:** Simple and structured fields for personal info, experience, education, and skills.
- **Real-time Preview:** See template changes dynamically as you type.
- **RTL & Arabic Typography:** Optimized layout with clean Arabic fonts and Right-to-Left formatting.
- **PDF Export / Print:** Clean, single-click export option formatted for printing or downloading as PDF.
- **Fully Responsive:** Works seamlessly across desktops, tablets, and mobile devices.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (Vanilla JS)
- **Styling:** Custom CSS Flexbox/Grid with RTL Support
- **Deployment:** GitHub Pages
